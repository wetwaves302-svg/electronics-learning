# 免費看到學生作答情形(Google 表單 + 試算表)

網站放在 GitHub Pages(免費),不需要自己的伺服器。學生同意後,練習紀錄會自動送到你的 Google 表單,存進你的 Google 試算表;你把試算表下載成 CSV,拖進網站的「教師看板」就能看到分析(總覽、每位學生、每題首次答對率、最常見錯誤、需要補救的學生)。

## 一次性設定(約 10 分鐘)
1. 用 Google 帳號建立新的 **Google 表單**,標題例如「電子學練習紀錄」。
2. 新增兩個題目:
   - 題目名稱 **學生**,類型 **簡答**
   - 題目名稱 **紀錄**,類型 **段落**
3. 右上角「設定」:**不要**勾選「限制 1 次回覆」,也**不要**要求登入(學生不需要 Google 帳號)。
4. 「回覆」分頁 → 「連結至試算表」,建立試算表。
5. 右上角 ⋮ → **取得預先填入的連結**:在「學生」欄輸入 `STUDENT`、在「紀錄」欄輸入 `DATA` → 按「取得連結」→ 複製連結。
6. 到網站的「教師看板」(頁尾「教師看板」)→ 展開「設定小幫手」→ 貼上連結,它會產生設定內容。
7. 把那段內容貼進儲存庫的 `app/public/config.json`(在 GitHub 網頁上按鉛筆編輯並 Commit 即可,或交給 Claude 更新)。約 1 分鐘後網站自動更新。
8. 用手機打開網站,首頁會出現「讓老師看到你的練習情形」卡片。自己先試一次:輸入名字、勾選同意、做一題,稍後到試算表應該看到新的一列。

## 平常怎麼看
1. 打開試算表 → 檔案 → 下載 → **逗號分隔值 (.csv)**。
2. 網站「教師看板」→ 選擇這個檔案。分析在你的瀏覽器裡完成,**不會上傳到任何地方**。
3. 想看最新情形,重新下載、重新選擇即可。

## 隱私與限制
- 學生需要自己輸入「班級 座號 姓名」並勾選同意才會傳送;可隨時停止傳送(已傳的不會收回)。
- 傳送的只有:你輸入的名字、答題對錯、作答方式、時間、錯誤類型。沒有其他個人資料。
- 試算表是你的 Google 帳號的資料,請保管好分享權限,不要公開連結。
- 這個做法**沒有帳號密碼**:知道網址的人可以假冒別人送出資料。適合課堂輔助與觀察,不適合當成績依據。
- 學生換手機時,紀錄不會跟著過去(各裝置分開存);但老師端會把同一個名字的紀錄合併。名字請學生輸入一致。
- 沒有「指定練習」與「題目審核」功能(這些需要完整版伺服器,見 deployment.md)。
- Google 表單可能因為異常大量的送出而限制;以一個班級的使用量不會有問題。
