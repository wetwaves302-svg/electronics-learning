```
  │                                   └─ 相位、sin/cos 轉換 ─ 同頻合成 ─ 交直流混合有效值

        └─ PN 接面、障壁電壓 ─ 順/逆偏 ─ V-I 特性 ─ 動態電阻、溫度效應
              └─ 理想二極體模型 ─ 半波整流 ─ 全波/橋式整流 ─ PIV、漣波因數 ─ 濾波
                                        (需先會:有效值、平均值、頻率)
```

## E. 動畫與互動需求(初稿)

1. 正弦、方波、三角、鋸齒波:可調 V_m、f、工作週期,同步顯示 V_av、V_rms、FF、CF。(計算式明確,可精確)
2. 相位差:兩正弦波移相疊加。
3. 價電子/自由電子/電洞:能帶示意與 N/P 型摻雜。(概念示意,需標明)
4. PN 接面順逆偏:空乏區變化與 I-V 曲線連動。(概念示意加指數公式曲線)
5. 理想二極體電路:導通判斷與等效開關。
6. 半波、全波、橋式整流:電流路徑、輸出波形、PIV 標示。
7. 濾波電容:輸出波形與漣波(可用 RC 放電精確計算)。

### 教材本身有問題或需處理的地方(已定案)

教師表示無電機專業背景,授權由我依學科正確性選擇最佳解讀。以下為我的決定與理由,**這些決定仍會記錄在版本紀錄,日後可由任何有專業的審查者推翻。**

1. **V_T 取值(WB2-MC-05)**:V_T=kT/q,25℃ 約 25.7mV,300K 約 25.9mV;習作取 25mV,講義取 26mV,兩者都是合理近似。
   **決定:** 本單元統一以 V_T=25mV 計算,因為這是選項中唯一能得到的值(25Ω);教學文字註明「室溫約 25～26mV,依題目給定的值計算」。其他章節若題目另給 26mV,依題目給的值。
2. **印刷錯字(WB1-PY-02)**:題幹「T₂ = = 2s」多一個等號,題意不變。**決定:** 收錄時修正為「T₂ = 2s」,在版本紀錄註明。
3. **VLSI 閘數(WB1-MC-03)**:講義沒有數字。臺灣技職電子學教科書常見分類以 1,000 閘作為 VLSI 下限,與習作答案一致。**決定:** 收錄為習作答案 C,題目註明「依本教材分類」,不把它當成國際通用的絕對定義。
4. **WB2-PY-05 沒有餘裕**:PIV=24√2≈33.94V,34V 是唯一達標的選項。**決定:** 答案維持 D,解析補充「實務上應選更高額定值」。
5. **缺漏或未說明近似的解析**:WB2-MC-11(無詳解)、WB2-MC-12(三角形漣波近似 V_dc=V_p−V_r/2)、WB2-MC-03(n≈N_d 需 N_d≫n_i)。**決定:** 由我補寫並標明適用條件,並標示為「解析待驗證」,不計入已完成題數,直到有專業審查者確認。
6. **WB2-QA-01 圖 (7)**:已細數,答案成立(見上表)。圖中符號是示意性手繪,數量不嚴格;遊戲與解題畫面中改以我重繪的 SVG(符號數量嚴格相等)呈現,保留原圖作為對照。
