# 電子學 I 互動學習平台

技術型高中電子學互動學習網站。範圍:第一次段考,習作 1-1 ~ 2-3(整流與濾波)。

**網站:** https://wetwaves302-svg.github.io/electronics-learning/

## 內容
- 5 個單元的互動教學(波形、半導體、PN 二極體、整流濾波等,圖表由公式即時算出)
- 習作 49 題逐題練習:三層提示、七步驟解題教練(老師帶著做 / 一起想一想 / 換你自己做)、變化題
- 18 款知識遊戲(沒有計時、答錯可重試,有音效與慶祝回饋)
- 錯題本(自動蒐集,不需手動收藏)與學習紀錄(區分「曾經答對」與「不依賴提示答對」)
- 教師後台(`server/`,需另外架設):班級、學生、分析、指定練習、題目審核與版本紀錄、Excel 匯出

GitHub Pages 上是**單機版**:不需登入,紀錄只存在各人的瀏覽器。完整版(含教師後台)的架設方式見 [docs/deployment.md](docs/deployment.md)。

教材著作權屬原出版者與原作者所有。本站為教學輔助,**非官方產品**;圖為重新繪製;互動教學、教練、遊戲等為本站編寫。
題目與解析目前尚未經專業教師審核,以授課教材與老師講解為準。教材 PDF 不包含在本儲存庫中。
